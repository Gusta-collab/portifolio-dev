Sobre

Soluções completas para desktop e automação.

Tenho experiência no desenvolvimento de aplicativos desktop utilizando C# e Python, criando soluções corporativas sob medida. Desenvolvo e integro ferramentas aos processos de empresas, além de prestar suporte aos usuários e identificar oportunidades de melhoria. Meu foco é criar soluções práticas e organizadas que contribuam para a otimização de processos, automação de tarefas e maior eficiência nas rotinas da equipe.

Vou além da simples automação de tarefas: trabalho com a integração profunda de sistemas, manipulação de dados em tempo real e geração automatizada de relatórios técnicos (Excel e PDF). O objetivo é transform fluxos manuais demorados em ecossistemas rápidos, seguros e padronizados.

Sistemas Desktop (C# e Python)

Desenvolvimento de softwares robustos com interfaces intuitivas para gerenciar fluxos operacionais, checklists e banco de dados locais.

Integração e Relatórios

Comunicação direta com o Pacote Office, geração silenciosa de laudos em PDF e gerenciamento automatizado de arquivos em servidores.

Automação de Processos

Criação de scripts web e ferramentas locais que executam tarefas repetitivas em lote, aumentando a produtividade e eliminando o erro humano.

Projetos

Automação eCAC

Aplicação desktop em Python para automação e organização de processos fiscais no e-CAC. Realiza a coleta de documentos, organização por cliente, processamento em lote e integração com Google Drive, reduzindo tarefas manuais e aumentando a eficiência dos processos.

Python Selenium CustomTkinter Google Drive API PyInstaller

Extrator Automático PGDAS

Aplicação desktop em Python para automatizar a consulta e extração de declarações PGDAS-D diretamente do e-CAC. Possui interface gráfica, organização automática dos documentos por cliente, consulta de diferentes anos e geração dos arquivos em PDF.

Python Selenium CustomTkinter Automação Web

Checklist Automático

Aplicação desktop em C# desenvolvida para padronizar e automatizar o processo de checklists operacionais de equipamentos como Vibrofit e Safer. O sistema realiza a leitura de arquivos de texto, gerencia a validação de códigos das peças via interface e integra os dados processados abrindo as planilhas de checklist finais diretamente no Excel.

C# Windows Forms Excel Interop Automação

Gerador de Laudos Técnicos

Sistema desktop em C# criado para emissão automatizada de laudos de qualidade de múltiplos equipamentos, incluindo controle de parâmetros elétricos e térmicos. O software coleta dados do operador, injeta e calcula valores em planilhas Excel em segundo plano, e exporta o laudo final em PDF de forma silenciosa, já enviando cópias de backup para o servidor da rede.

C# Windows Forms Manipulação de PDF Integração de Sistemas
