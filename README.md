# Portfólio — Gustavo Alexandre

A versão navegável do portfólio fica em `static-export/` e usa HTML, CSS e JavaScript, sem dependências de build.

Para visualizar localmente com Node.js:

```sh
node preview.mjs
```

Abra `http://127.0.0.1:4173`. Para encerrar, use `Ctrl+C` no terminal.

O tema claro/escuro é salvo no navegador. Os cards de projetos abrem com o mouse, teclado ou toque. Os efeitos originais dos tubarões ficam em `static-export/script.js`.
