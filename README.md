# Portfólio — Gustavo Alexandre

Este diretório contém o site completo: HTML, CSS, JavaScript, imagens, ícones, áudio e avisos de licença. Os arquivos de mídia ficam em `assets/`, separados por tipo. Não há dependências de build.

Para visualizar localmente com Node.js:

```sh
node preview.mjs
```

Execute o comando de dentro deste diretório e abra `http://127.0.0.1:4173`. Para encerrar, use `Ctrl+C` no terminal.

O tema claro/escuro é salvo no navegador. Os cards de projetos abrem com o mouse, teclado ou toque. Os efeitos dos tubarões ficam em `assets/js/shark-effects.js`.
